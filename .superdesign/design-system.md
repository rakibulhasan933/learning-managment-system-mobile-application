# BanglaBox student mobile redesign system

BanglaBox is a focused student learning companion for continuing web enrollments on mobile, including course progress, lesson content, quizzes, assignments, video playback, and offline downloads.

## Direction

Keep the existing dark editorial identity but improve hierarchy, scanability, and touch ergonomics. Use the real BanglaBox logo asset. Prefer calm, dense learning surfaces over marketing-style screens. Main navigation remains Home, My classes, and Downloads.

## Tokens

- Background: `#12151C`
- Surface: `#1B1F29`
- Elevated surface: `#222733`
- Primary accent: `#C9A15A`
- Success: `#3F7A6B`
- Text: `#F2EFE7`
- Muted text: `#8B8D98`
- Danger: `#E26D5A`
- Border: `rgba(242,239,231,0.12)`
- Display font: Georgia/serif
- UI font: platform sans-serif
- Page padding: 20px
- Card radius: 18–20px
- Primary actions: brass rounded pills

## Redesign scope

Redesign the student home/dashboard first as the anchor screen, preserving the existing information architecture and content: welcome identity, active/offline stats, continue-learning course card, completion progress, and bottom navigation. Design should extend cleanly to course outline, lesson player, quiz, assignment, and downloads.
